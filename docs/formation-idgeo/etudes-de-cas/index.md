Les études de cas permettent de mettre en pratique les connaissances et compétences acquises dans les différents blocs de formation.

## A03 — Accessibilité PMR

L'étude de cas A03 porte notamment sur l'exploitation de données d'accessibilité PMR.

Le scénario officiel concerne **Losse-en-Gelaisse**, tandis que les données utilisées pour réaliser concrètement les traitements sont situées à **Granville**.

La documentation présente progressivement :

- la compréhension de l'étude de cas ;
- l'avancement du projet ;
- la préparation et l'audit de la base PostgreSQL/PostGIS ;
- les contrôles qualité ;
- les traitements et analyses PMR ;
- les résultats cartographiques ;
- la diffusion des résultats.
