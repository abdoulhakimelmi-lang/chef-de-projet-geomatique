# 06 --- Retour du tuteur et évolution de la réflexion

## Validation de la démarche

Après avoir présenté les deux options à mon tuteur, il a confirmé qu'il
s'agissait bien des **deux scénarios à explorer** pour préparer les
futurs échanges avec le BSI.

## Trois dimensions à ajouter

Mon tuteur a demandé d'intégrer systématiquement : 1. **la sécurité
informatique** ; 2. **la souveraineté** ; 3. **la rationalisation
économique**.

``` text
              RÉFLEXION
                  │
       ┌──────────┼──────────┐
       ▼          ▼          ▼
   Sécurité   Souveraineté   Économie
```

## Pour l'option 1

Il faut vérifier : - si **ArcGIS Pro peut être installé sur les postes**
; - si **pgAdmin peut être utilisé sur les postes avec les données
hébergées à l'extérieur**.

La question devient donc : peut-on travailler localement tout en
conservant l'infrastructure distante, avec un accès réseau suffisamment
sécurisé ?

## Pour l'option 2

Le tuteur demande d'**impliquer le BSI** afin d'être accompagné dans la
sécurisation de l'infrastructure interne.

``` text
Pôle SIG + BSI
      │
      ▼
Architecture et sécurité
      │
      ▼
Infrastructure interne éventuelle
```

## Ce que ce retour change

Au départ, ma réflexion était surtout technique : serveur, VM, CPU, RAM,
stockage et PostgreSQL.

Le retour du tuteur élargit l'étude :

``` text
Technique
+ sécurité
+ souveraineté
+ économie
+ organisation avec le BSI
```

## Situation actuelle

À ce stade : - l'existant est documenté ; - deux options sont
identifiées ; - des informations complémentaires ont été obtenues auprès
d'Esri ; - le tuteur a confirmé les deux pistes ; - aucun scénario
définitif n'est encore choisi.

La prochaine étape sera de vérifier techniquement les options et de
préparer les échanges avec le BSI.
